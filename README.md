# Arijit Mondal — AI/ML & Full-Stack Developer Portfolio

A professional, high-performance portfolio web application built with **Angular 19** and **Three.js (WebGL 3D)**.

---

## 🌟 Key Features

1. **3D Interactive Neural Graphics (Three.js)**:
   - Dynamic real-time WebGL particle constellation & neural network canvas.
   - Cursor-reactive particle physics, synaptic pulses, and floating 3D wireframe geometries.
   - Smooth 60fps render loop decoupled from Angular's change detection zone.

2. **Angular 19 Frontend Architecture**:
   - Modern Angular Standalone Components & reactive Signals.
   - Cyber-Obsidian theme (`#070913`), electric cyan (`#00f0ff`), neural violet (`#8a2be2`), and glassmorphism panels.
   - Interactive category filters (`All`, `Agentic AI & RAG`, `Conversational GenAI`, `Full-Stack & Cloud`, `Mobile`).
   - Deep-dive project architecture and 9-agent pipeline modals.

3. **Complete Portfolio Projects (All 7 Projects)**:
   - **HomeworkPlus** (Flagship AI Learning Platform - 9-agent pipeline, OCR, RAG, Whisper, WebSockets)
   - **RFP Agent** (Enterprise Request-for-Proposal Agentic Analyzer & ChromaDB retrieval)
   - **AI Yoga Coach** (Google Gemini 2.5 Flash, adaptive coach personas, safety guardrails)
   - **AI Insurance Portal** (Zoneless Angular 17 Signals, SQL knowledge base)
   - **Real-Time Chat Application** (Spring Boot, WebSocket STOMP, Keycloak OAuth 2.0)
   - **Quiz Web App** (Spring Boot, Angular, MySQL quizzing engine)
   - **AgriDirect Mobile** (Smart India Hackathon, Android Jetpack Compose, Firebase)

4. **Interactive AI Technical Screening Terminal**:
   - Interactive command-line simulator demonstrating architectural reasoning across RAG, chunking, AI Agents vs APIs, Celery/Redis, and WebSockets.

5. **Integrated Career & CV System**:
   - Role badge: **Full Stack Developer @ Virtual Employee Pvt Ltd** (ID: `TK12691`).
   - Education: **B.Tech in CST (AI & ML)** at **MCKV Institute of Engineering, Howrah**.
   - Interactive printable/downloadable CV viewer modal.

## 🚀 Quick Start

### Start Angular Dev Server:
```powershell
.\start-all.ps1
```
Or:
```bash
cd frontend
npm start
```
Open **`http://localhost:4200/`** in your browser.

---

## 📦 Build for Production (Deploy to Vercel / Netlify / GitHub Pages)
```bash
cd frontend
npm run build
```
Output files are generated in `frontend/dist/frontend/browser`.
